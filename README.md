# How can Dex win back Van with his suggestions?

A private, password-gated page where one suggestion can be written per day (Pacific Time), shared live between everyone who has the link.

- `index.html` — the whole app (HTML, CSS, JS).
- `firebase-config.js` — your Firebase web config (the only file you need to edit).
- `firestore.rules` — paste into Firebase console → Firestore Database → Rules.

Hosted with GitHub Pages. The password and bypass word are stored as SHA-256 hashes, not plain text.
